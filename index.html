Google Sign-In Checklist

  1. Your OAuth client must be a Web application.
  2. Authorized JavaScript origin must include https://masterproof.github.io.
  3. If your OAuth app is in Testing, add your Google account under Audience → Test users.
  4. Enable both Google Drive API and Google Picker API.
  5. Your regular API key website restrictions should include https://masterproof.github.io/* and https://docs.google.com/*.
  6. Use the Google Cloud Project Number as the App ID. You can find it under IAM & Admin → Settings.

Why the old screen could fail

Google Picker still uses an OAuth Client ID, API key, and App ID/project number, but V4 reads all three from google-config.js so you do not type them into the webpage.

About AI images

GitHub Pages cannot safely hide a private AI service key because it is a static host. This build therefore asks for the key in the browser instead of hard-coding it into the public repository.
